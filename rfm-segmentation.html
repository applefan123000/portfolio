    How scoring works

    Scores

    Each metric is split into bands by percentile (quintiles by default). The most recent buyers, most frequent buyers and biggest spenders score 5; the least score 1. A customer's RFM code is the three scores together, e.g. 545.

    Segments

    Segments are assigned from the R and F scores using the standard RFM playbook (Champions, Loyal, At Risk, Hibernating…). Monetary value is shown per segment rather than used to draw the boundaries, so a segment stays comparable over time.

    Your CSV

    One row per order with columns customer_id, order_date (YYYY-MM-DD) and amount. An order_id column is optional — if present, repeat rows for the same order are counted once for Frequency. Everything runs in your browser; no data leaves the page.

    Sample data is a generated demo set of 521 customers and 2,590 orders over the last 12 months — replace it with your own file at any time.
